# xsystems — единое приложение (xsystem4 + xsystem35)

Форк [`xsystem4-android`](https://github.com/kichikuou/xsystem4-android), собранный в **одно** Android-приложение, запускающее игры AliceSoft на двух движках:

- **xsystem4** — System 4 (напр. Daiteikoku «Великая империя»)
- **xsystem35** — System 3.x, включая System 3.9 (напр. Daiakuji «大悪司»)

Плюс доработки: **озвучка ADV-текста (TTS)**, **читы** (просмотр/скан/правка переменных VM), фильтр голосов по языку, приглушение музыки при чтении, авто-листание.

Личное использование (коммерческие игры; APK не распространяется).

## Архитектура

- **Пакет / applicationId:** `io.github.rufim.alice`. Не конфликтует с оригинальным `io.github.kichikuou.xsystem4`.
- **Два движка — две `.so`** в общем `jniLibs`, Gradle пакует их в один APK. Оба линкуются с **единым `libSDL2.so` 2.32.10** (последний SDL2, ABI-совместим назад с 2.30.9, которую использует xsystem4).
  - `build-shared-libs.sh` собирает xsystem4 → `libxsystem4.so`, `libcglm.so`.
  - `build-xsystem35.sh` (вызывается в конце) собирает xsystem35 своим android-CMake → `libxsystem35.so` + `libSDL2.so`/`ttf`/`mixer` + `libwebp.so`/`libsharpyuv.so`, кладёт в тот же `jniLibs` (его `libSDL2.so` 2.32.10 становится общим).
  - **Java-glue SDL** в приложении обновлён до 2.32.10 (совпадает с нативным; иначе проверка версии рвёт `onCreate` → `mSurface=null` → краш).
- **Изоляция процессов:** каждая игровая активити в своём процессе (`:engine4` / `:engine35`) — ради чистой переинициализации SDL при каждом запуске (не про параллельность — игры всегда по одной).
- **Определение движка** по маркер-файлам в папке игры: `System39.ain` → xsystem35; `System40.ini`/`AliceStart.ini` → xsystem4.
- **Общий Kotlin** (TTS, читы, ML Kit, боковая панель) — в `EngineActivity`; `XSystem4Activity`/`XSystem35Activity` — тонкие наследники. Единый `NativeBridge`; оба движка экспортируют `Java_io_github_rufim_alice_NativeBridge_*`.

## Сборка

```sh
export ANDROID_SDK_ROOT=~/Android/Sdk
export ANDROID_NDK_HOME=~/Android/Sdk/ndk/30.0.14904198
export ABI_NAMES="arm64-v8a x86_64"
git clone --recursive <this-repo>
./build-shared-libs.sh          # собирает обе .so движков в jniLibs
cd project && ./gradlew installDebug
```

Требуется: Android SDK/NDK (r30+), CMake 3.21+, flex, bison. Системный CMake 4.x — сборка тянет старые зависимости, для них скрипт передаёт `-DCMAKE_POLICY_VERSION_MINIMUM=3.5`.

## Как класть игры

Скопировать папку игры в `Android/data/io.github.rufim.alice/files/` на устройстве (через MTP).

**Важно при заливке через `adb push`:** каталог создаётся под пользователем `shell`, и приложение не может в него зайти/писать (сейвы, кэш иконки). Выдать доступ:

```sh
adb shell chmod -R 0777 /sdcard/Android/data/io.github.rufim.alice/files/<Игра>
```

(Через MTP такой проблемы нет — файлы принадлежат приложению.)

## Возможности (движко-независимые)

Боковая панель (ярлык у правого края) → **Озвучка (TTS)** и **Читы**.

### TTS
- Читает ADV-текст; язык определяется по сегментам (кириллица/кана-кандзи/латиница).
- Выбор движка TTS, **язык** (все, для которых у движка есть голоса) и **голос** на каждый язык.
- Приглушение музыки на время речи (настраиваемый процент).
- Авто-листание после чтения (игровой режим АВТО лучше выключить).
- Кнопка стоп/плей (низ-слева). Игровой «ПРОПУСК» останавливает чтение.
- **Не читать страницы (номера через запятую)** — подавление озвучки на меню/статус-экранах. Для xsystem35 по умолчанию `11` (титул/хаб Daiakuji со статусом «35Y 1M4W…»).

### Читы
- Список именованных глобальных переменных VM со значениями.
- Скан по значению в стиле Cheat Engine (найти → изменить в игре → сузить) и правка.
- Опциональный перевод имён переменных через Google ML Kit (JA→RU).
- System 4 — 32-битные переменные; System 3.x — 16-битные (0..65535).

## Особенности реализации System 3.x (xsystem35)

- **TTS** через встроенный `texthook` движка (Android-режим): `texthook_message/newline/nextpage/keywait` → JNI. Озвучивается только реально отображаемый текст (гейт по `mg_dspMsg` — не читать невидимые строки меню/предметов).
- **Читы** поверх `variable.c` (`v_ref`/`v_name`/`varPage`).
- **Авто-листание** — синтетическим тапом с паузой между DOWN и UP (движок откладывает применение касания на `TOUCH_EVENT_DELAY`; мгновенный тап теряется). Завершение чтения определяется по `tts.isSpeaking()`, а не по счётчику `onStart/onDone` (движок TTS теряет `onDone` промежуточных реплик).
- **Приглушение музыки** — через систему громкости движка (`volume_duck`, BGM-каналы).

Исходники движка — сабмодуль [`Rufim/xsystem35-sdl2`](https://github.com/Rufim/xsystem35-sdl2).
